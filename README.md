# Counter Project

A simple counter web application built using HTML, CSS, and JavaScript.

## Features

- Increase counter value
- Decrease counter value
- Reset counter
- Responsive UI
- Simple and clean design

## Tech Stack

- HTML5
- CSS3
- JavaScript
